MODELS OF
TRAFFIC FLOW

Mathematical Models for Traffic Stream Analysis

Model 01

Greenshield Model

The Greenshield model assumes a linear relationship between traffic speed and traffic density. It is one of the simplest and most widely used traffic flow models.

Let \(u\) represent the average traffic speed and \(k\) represent traffic density.

Basic assumption: Speed decreases linearly with density and satisfies the two boundary conditions.
  • Free-flow condition(speed at zero density):\[u(0)=u_f\]
  • Jam condition(speed is zero at jam density \(k_j\)):\[u(k_j)=0\]

1. Speed–Density Relationship

The linear relationship can be written as:

\[ u = mk + b \]

A line passes through \((0,u_f)\) and \((k_j,0)\), so the slope,\(m\), is:

\[m=\frac{u_2-u_1}{k_2-k_1}\] \[m=\frac{0-u_f}{k_j-0}\] \[m=-\frac{u_f}{k_j}\]

Plugging this into the equation:

\[u(k)=\left(-\frac{u_f}{k_j}\right)k+b\]

Using one of the boundary conditions:

\[u(0)=u_f\]

The equation becomes,

\[u_f=\left(-\frac{u_f}{k_j}\right)(0)+b\] \[b=u_f\]

Hence:

\[u=\left(-\frac{u_f}{k_j}\right)k+u_f\]

Factoring out \(u_f\):

\[\boxed{u=u_f\left(1-\frac{k}{k_j}\right)}\]

2.Flow–Density Relationship

Traffic flow is defined as:

\[q = ku\]

Substituting the Greenshield speed-density equation:

\[q=k\left[u_f\left(1-\frac{k}{k_j}\right)\right]\]

Therefore:

\[\boxed{q =u_f k-\frac{u_f}{k_j}k^2}\]

Maximum flow occurs when the derivative of flow with respect to density is zero:

\[\frac{dq}{dk}=0\]\[u_f-\frac{2u_f}{k_j}k=0\] \[(k_j)(u_f)=2(u_f)(k)\]

Solving for the critical density:

\[\boxed{k_{\text{critical}}=\frac{k_j}{2}}\]

Solving for the critical speed:

\[u_{\text{critical}}=u_f\left(1-\frac{k_{\text{critical}}}{k_j}\right)\] \[u_{\text{critical}}=u_f\left(1-\frac{k_j/2}{k_j}\right)\] \[u_{\text{critical}}=u_f\left(1-\frac{1}{2}\right)\]

The corresponding critical speed is:

\[\boxed{u_{\text{critical}}=\frac{u_f}{2}}\]

Solving for the maximum flow:

\[q = ku\] \[q_{\max}=k_{\text{critical}}u_{\text{critical}}\] \[q_{\max}=\left(\frac{k_j}{2}\right)\left(\frac{u_f}{2}\right)\]

Therefore, the maximum flow is:

\[\boxed{q_{\max} =\frac{u_f k_j}{4}}\]

3. Speed–Flow Relationship

Traffic flow is defined as:

\[q = ku\]

From the Greenshield speed-density equation:

\[q=k\left[u_f\left(1-\frac{k}{k_j}\right)\right]\]

We express k in terms of u:

\[u=u_f-\frac{u_fk}{k_j}\] \[uk_j=u_fk_j-u_fk\] \[u_fk=u_fk_j-uk_j\] \[k=k_j-\frac{uk_j}{u_f}\]

Going back to our original equation:

\[q = ku\] \[q=\left(k_j-\frac{uk_j}{u_f}\right)u\] \[q=uk_j-\frac{u^2k_j}{u_f}\]

Therefore, the speed–flow relationship for the Greenshield model is:

\[\boxed{q=uk_j-\frac{u^2k_j}{u_f}}\]
Model 02

Greenberg Model

The Greenberg model assumes that the relationship between speed and density follows a logarithmic function rather than a linear function.

Basic assumptions:
  • Traffic flow behaves similarly to compressible fluid flow
  • Speed-density relationship is logarithmic
  • Speed becomes zero at jam density
  • Model is most applicable to dense urban traffic conditions

1. Speed–Density Relationship

The Greenberg model is expressed as:

\[\boxed{u = u_0\ln\left(\frac{k_j}{k}\right)}\]

where \(u_0\) is a model parameter associated with the speed at critical conditions.

2. Flow–Density Relationship

Starting with:

\[u = u_0\ln\left(\frac{k_j}{k}\right)\]

Since:

\[q=ku\]

Substitute the speed equation:

\[q = k u_0\ln\left(\frac{k_j}{k}\right)\]

Therefore:

\[\boxed{q = u_0 k\ln\left(\frac{k_j}{k}\right)}\]

Solving for the Critical Density:

\[q = k u_0\ln\left(\frac{k_j}{k}\right)\] \[q = u_0 k \left(\ln(k_j) - \ln(k)\right)\] \[q = u_0 \left[k\ln(k_j) - k\ln(k)\right]\]

Maximum flow occurs when:

\[\frac{dq}{dk}=0\]

Differentiating the flow equation gives:

$$\frac{dq}{dk} = u_0\left[\ln(k_j)-\left\{k\left(\frac{1}{k}\right)+\ln(k)\right\}\right]$$ $$\frac{dq}{dk} = u_0\left[\ln(k_j)-\left\{k\left(\frac{1}{k}\right)+\ln(k)\right\}\right]$$ $$\frac{dq}{dk} = u_0\left[\ln(k_j)-1-\ln(k)\right]$$

Setting this equal to zero:

$$u_0\left[\ln(k_j)-1-\ln(k)\right] = 0$$ $$\left[\ln(k_j)-1-\ln(k)\right] = 0$$ $$\left[\ln(k_j)-\ln(k)-1\right] = 0$$ $$\ln\left(\frac{k_j}{k}\right) = 1$$ $$e^{\ln\left(\frac{k_j}{k}\right)}=e^1$$ $$\frac{k_j}{k}=e$$

Therefore:

\[\boxed{k_c=\frac{k_j}{e}}\]
Solving for the Critical Speed:

\[u = u_0\ln\left(\frac{k_j}{k}\right)\] \[u_c = u_0 \ln\left(\frac{k_j}{k_c}\right)\] \[u_c = u_0 \ln\left(\frac{k_j}{k_j/e}\right)\] \[u_c = u_0 \ln\left(\frac{k_j \cdot e}{k_j}\right)\] \[u_c = u_0 \ln(e) = u_0\]

Hence, the critical speed is,

\[\boxed{u_c = u_0}\]
Model 03

Underwood Model

The Underwood model represents the relationship between speed and density using an exponential function. Unlike Greenshield, it does not assume a linear decrease in speed.

Basic assumption: Speed decreases exponentially as traffic density increases.

1. Speed–Density Relationship

The Underwood model can be expressed as:

\[ \boxed{ u = u_f e^{-k/k_0} } \]

where \(k_0\) is a density parameter controlling the rate at which speed decreases.

2. Deriving the Flow–Density Relationship

Starting with the fundamental relationship:

\[ q=ku \]

Substitute the Underwood speed-density equation:

\[ q = k \left( u_f e^{-k/k_0} \right) \]

Therefore:

\[ \boxed{ q = u_f k e^{-k/k_0} } \]

3. Determining Critical Density

Maximum flow occurs when:

\[ \frac{dq}{dk}=0 \]

Differentiating:

\[ \frac{dq}{dk} = u_f e^{-k/k_0} \left( 1-\frac{k}{k_0} \right) \]

Setting the derivative equal to zero:

\[ 1-\frac{k_c}{k_0}=0 \]

Thus:

\[ \boxed{ k_c=k_0 } \]

4. Critical Speed

At critical density:

\[ u_c = u_f e^{-k_c/k_0} \]

Since \(k_c=k_0\):

\[ \boxed{ u_c=\frac{u_f}{e} } \]

5. Maximum Flow

Substituting the critical conditions:

\[ q_{\max} = k_c u_c \]
\[ \boxed{ q_{\max} = \frac{u_f k_0}{e} } \]
